# agents/

Общие конфиги AI-агентов для всех машин.

## Где что лежит

Конфиги агентов лежат **в корне репозитория** (не здесь), потому что
агенты подхватывают их по расположению:

| Файл/каталог     | Кто читает                              |
|------------------|-----------------------------------------|
| `AGENTS.md`      | Devin, Codex, и др. (agents.md standard)|
| `CLAUDE.md`      | Claude Code (нет — см. заметку ниже)    |
| `GEMINI.md`      | Gemini CLI                              |
| `opencode.json`  | opencode                               |
| `.mcp.json`      | MCP-серверы (общие для агентов)         |
| `.claude/`       | настройки/скиллы Claude Code            |
| `.gemini/`       | настройки Gemini CLI                   |
| `.grok/`         | настройки Grok CLI                     |
| `.devcontainer/` | devcontainer-окружение (pwsh + python)  |

Этот каталог — для заметок и шаблонов, которые не должны жить в корне.
Например: шаблон `AGENTS.md` для другого репо, который можно скопировать.

## Идея

`remenv` — единая точка: клонировал репо → все агенты видят одни и те же
MCP-серверы, правила и скиллы. Машино-специфичное — в `hosts/<machine>.md`.
