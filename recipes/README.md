# recipes/

Runbook'и и записки — один рецепт на markdown-файл (`<name>.md`).
Идея: то, что должно быть под рукой на любой машине, без поиска
по всем `~/code`.

Открыть рецепт из shell (после подключения `remenv.sh`):

```bash
remenv-recipe <name>   # откроет recipes/<name>.md в $EDITOR/less
ls recipes/            # список доступных
```

## Формат

Свободный markdown. Полезная структура:

```markdown
# Название рецепта

**Контекст:** где/когда применяется, какие хосты/сервисы затронуты.

## Шаги
1. ...

## Проверка
- как убедиться, что сработало

## Откат / Troubleshooting
- типичные ошибки и решения
```

Секреты в рецептах не храним — только ссылки на то, где они лежат
(`~/.config/...`, переменные окружения).
